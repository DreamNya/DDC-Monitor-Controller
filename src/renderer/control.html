操作目标

选择特定显示器

亮度 / 对比度的相对百分比调节会限制在 0 到显示器返回的 maximum；其余 Value 不做 0–100 或显示器范围兜底；VCP Code 可自行修改，数值支持十进制或 0x 前缀十六进制

预设功能

高级 VCP 预设操作

按显示器返回的 maximum 计算百分比增减量，并将最终写入值限制在 0～maximum，即使当前值已在边界，执行或快捷键仍会发送一次写入

Value 将原样转换为整数后发送，无最大值最小值兜底

切换后关闭 UI 面板 写入成功后销毁 WebView 释放内存

默认 VCP Code 为 0x60；具体输入源 Value 由显示器决定

默认 VCP Code 为 0xD6；具体电源模式 Value 由显示器决定
